1 · Restriccions de disseny (llegir primer)

  • Un sol fitxer index.html: HTML + CSS + ~12 scripts inline + dades. Sense build, sense bundler, sense dependències externes (només font Inter i iframes Drive/YouTube).

  • Strings visibles siempre vía L(ca,es); HTML vía esc(); texto plano vía vidTitleRaw().
  • CSS nuevo → cola final («CUA FINAL NETA»); nodos runtime → RUNTIME_IDS/REPAINT.
  • Editar datos persistidos → pasar por OV y llamar hydrateCourse(); render(); (y repaint() si el gestor está abierto).
  • No mutar arrays de levelIds() sin applyLevelIds() + render().

14 · Regresión mínima antes de cada release

  1. Guardián ausente + consola limpia.
  2. Script de invariantes del Manual básico §5 (duplicados y residuos).
  3. Flujos: Seguimiento (play, ficha, aplazar, ⓘ), Libre (búsqueda, bloques, adjuntos), edición (crear/borrar adjunto y vídeo, orden), guardar→reabrir, PWA móvil.
  4. Cambio de idioma CA↔ES en cada vista y en el gestor.
